How many tabs do you have open? **365** — a full year of tabs, one for every
day, never closed. The honest count of a chronic "read later" hoarder: big
enough to surprise, ordinary enough to believe.

## Run it

```sh
python3 main.py
```

The program prints `365` and, when `MAKEFUN_OUTPUT_DIR` is set, writes it
(with no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` — exactly one
number in digits, nothing else.
